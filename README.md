# PDF Inspect

PDF Inspect 是一个可视化 PDF 文件检查器（Web 版 MVP）。

当前实现了以下交互主链路：

1. 打开本地 PDF 文件。
2. 翻页与缩放查看。
3. 点击分析后提取页面文本与基础路径/线条元素。
4. 鼠标悬浮元素时显示高亮框。
5. 点击元素后左侧详情栏展示属性。
6. 通过 Cmd/Ctrl+F 打开右侧搜索栏并聚焦。
7. 输入框回车执行搜索（支持关键字、多关键字 OR、正则模式）。
8. 点击搜索结果后跳页定位并高亮元素，同时联动左侧详情。

## 本地运行

```bash
npm install
npm run dev
```

生产构建与静态检查：

```bash
npm run build
npm run lint
```

## 搜索语法

1. 普通关键字：直接输入，例如 `invoice`。
2. 多关键字 AND：空格分隔，例如 `invoice total`。
3. OR 条件：用 `|` 分组，例如 `invoice total | subtotal`。
4. 正则模式：勾选“使用正则模式”后按回车。

## 当前技术栈

1. React + TypeScript + Vite
2. PDF.js (`pdfjs-dist`)

## 已知限制（MVP）

1. 分析暂在主线程执行，大文件时可能出现短暂卡顿（下一步迁移 Web Worker）。
2. 路径/线条属性目前为基础提取，颜色与复杂关系仍需增强。
3. 当前仅支持单文件内检索，不支持跨文件索引。

## 下一步

1. 将分析任务迁移至 Web Worker，支持取消与分批回传。
2. 为线条/路径补充颜色、绘制状态和关系信息。
3. 增加搜索结果虚拟列表与命中上下文预览。
